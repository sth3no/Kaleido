## 1. Shrnutí

Kaleido je desktopový video přehrávač postavený na **upstream libmpv** (nikdy fork) s liquid glass UI
(Tauri 2 + Rust + React/TypeScript) a **obchodem s mpv pluginy na jedno kliknutí**. Pluginy jsou
běžné mpv skripty, takže funguje existující ekosystém. Verze 1.0 je pro Windows a musí působit
**hotově a vyladěně**, ne jako demo.

### Proč

Žádný existující projekt nespojuje krásné UI, obchod s pluginy na jedno kliknutí a výchozí balíček
essentials:

| Projekt | Proč nestačí |
|---|---|
| IINA | jen macOS, vlastní JS API, běžné mpv skripty nejedou |
| mpv.net | Windows, bez obchodu |
| MPV-EASY Player | Windows, skripty se kopírují ručně |
| ImPlay | ImGui, bez obchodu |
| frame-player | Tauri 2 + libmpv, bez pluginů (**technická reference** pro vkládání videa) |
| mplug, mpsm | správci skriptů pro příkazovou řádku |
| uosc | OSC uvnitř mpv, ne samostatný přehrávač |
| Spool | Jellyfin klient (Qt), forkuje libmpv kvůli HDR |

### Úspěch 1.0

- Všechny obrazovky z kapitoly 8 hotové v češtině i angličtině, bez zástupných textů.
- Splněné výkonnostní limity (kapitola 13) a ruční testovací matice (kapitola 12).
- Essentials fungují po instalaci bez jakéhokoli nastavování.
- Katalog obsahuje 50–100 ručně vybraných, ověřených pluginů.
- Stabilní 1.0 je podepsaná (SignPath) a aktualizuje se sama.

## 2. Vize, roadmapa a rozsah

„VLC na drogách“: nejlepší přehrávač, do kterého postupně přibude všechno. **Jen desktop**
(Windows → macOS → Linux), mobil ve vizi není.

1. **Kaleido 1.0 (Windows)** – tato specifikace
2. Stahování
3. AI nad videem (chat o přehrávaném videu, časové značky skáčou v přehrávači; Ollama/cloud)
4. macOS + Linux
5. Domovská obrazovka (nedávné, pokračovat od)
6. Knihovna médií
7. Síť a sdílení (DLNA/Chromecast, watch together)
8. *(daleká budoucnost)* obchod s tématy

Budoucí funkce jsou v 1.0 vidět jako stránky se štítkem **ROADMAPA** a odkazem na veřejnou roadmapu
(konstanta `ROADMAP_URL`, viz 11.7).

### Mimo rozsah 1.0

Stahování (a s ním samostatný ffmpeg), AI, knihovna, domovská obrazovka a „Pokračovat ve sledování“,
macOS/Linux, síť a sdílení, obchod s tématy, Microsoft Store/MSIX, moderní kontextové menu
Windows 11, ARM64, jakákoli telemetrie, příkazová paleta a karta náhledu odkazu v aplikaci
(zamítnuto, viz 9.4), samotná akce „Přehrát v Kaleidu“ v Raycastu (přijde hned po 1.0, viz 9.4).

## 3. Technologie

| Oblast | Volba |
|---|---|
| Engine | **libmpv z upstreamu** jako DLL (`libmpv-2.dll`, Windows build od shinchira). Aktualizace = výměna DLL, nikdy vlastní patche. |
| Shell | **Tauri 2**: Rust jádro + React/TypeScript UI ve WebView2 |
| Video | mpv kreslí do **nativního podokna (`wid`) pod průhledným WebView2**; `vo=gpu-next`, `gpu-api=d3d11`, HDR přes `target-colorspace-hint` |
| Vazba na libmpv | vlastní tenká FFI vrstva nad stabilním C API `client.h`, DLL načítaná za běhu (`libloading`), kontrola `mpv_client_api_version` |
| UI | React 19, TypeScript (strict), Vite, Zustand pro stav, CSS proměnné pro design tokeny + CSS Modules, i18next |
| Balíčkovač | npm (stejně jako The Downloader), Cargo workspace |

Vzory: frame-player (`docs/architecture.md`), Stremio shell-ng.

**Zamítnuto:**
- **Electron**: Chromium chce celé okno, omezení průhledných oken, +100 MB, pomalejší start.
  Převzetí Node kódu z downloaderu je malá výhoda.
- **Electrobun**: vkládání okna přes FFI na mladém frameworku.
- **Qt/Flutter**: render API = bez HDR s upstream libmpv, C++/Dart.
- **Fork libmpv**: engine neudržujeme, bereme ho od upstreamu.

## 4. Architektura

### 4.1 Procesy

Jeden hlavní proces `Kaleido.exe` (Tauri + libmpv). Výjimky, každá s jediným účelem:

- **Hlídací proces pro pády**: tentýž `Kaleido.exe` spuštěný v režimu `--crash-server` (rozhoduje se
  na začátku `main`, ještě před inicializací Tauri a kontrolou jediné instance). Jen zapisuje minidump.
- **`kaleido-mpv.exe`**: minimální bezhlavý nástroj s rozhraním příkazové řádky jako mpv nad
  stejnou `libmpv-2.dll`. Existuje jen kvůli thumbfastu, který generuje náhledy v samostatném mpv
  procesu (`mpv_path` v `script-opts/thumbfast.conf`). Díky tomu nepřibalujeme celé `mpv.exe`.
- Krátkodobé procesy nástrojů (`yt-dlp`, `deno`), spouštěné jen z Rustu.

### 4.2 Rust moduly

| Modul | Odpovědnost | Závisí na |
|---|---|---|
| `player` | **jediný** mluví s libmpv: životní cyklus enginu, příkazy, sledované vlastnosti, události, restart s pokračováním | FFI |
| `surface` | nativní podokno pro video (teď Windows, abstrakce kvůli macOS/Linuxu), synchronizace s oknem, mini přehrávač, černá clona, oblasti skla → `glsl-shader-opts` | `player` |
| `input` | převod vstupu z UI na příkazy mpv (`keydown`/`keyup`, `mouse`, tlačítka, kolečko) | `player` |
| `plugins` | instalace, zapnutí/vypnutí, odinstalace, `plugins.json`, nastavení pluginů, přiřazení chyb z logu | `player`, `store` |
| `store` | stažení a ověření indexu katalogu, cache, kontrola aktualizací, instalace z URL | — |
| `themes` | design tokeny, témata, Mica/Acrylic, „snížit průhlednost“ | `surface` |
| `settings` | nastavení Kaleida (`settings.json`) a zápis do `mpv.conf`/`script-opts` | `player` |
| `tools` | správa yt-dlp a Deno (stažení, ověření, aktualizace), spouštění `yt-dlp -J` | — |
| `system` | protokol `kaleido://`, příkazová řádka, jediná instance, asociace souborů a jejich stav, hlídání pádů, bezpečný režim, logy | všechny |

Pravidla:
- **UI nikdy nemluví s mpv přímo**, jen přes typované příkazy a události (4.4).
- **Spouštění procesů a práce se soubory jsou jen v Rustu** (bezpečnostní hranice). UI nemá přístup
  k souborovému systému ani k shellu.
- Čistá TS logika z The Downloader (formáty a jejich řazení, odhady, parsování JSON z yt-dlp,
  grafy, přepisy) se převezme do UI i s testy. Logika pracující se soubory a procesy
  (`managed-binary`, `tool-freshness`, `tool-updates`, detekce prohlížečů pro cookies) se přepíše do Rustu.

### 4.3 Složky

### 4.4 Rozhraní UI ↔ Rust

Typované příkazy Tauri (výběr, plán je zpřesní):

| Příkaz | Účel |
|---|---|
| `player_load(sources, mode)` | otevřít soubory, složky nebo URL; `mode` = nahradit / přidat do playlistu |
| `player_command(cmd)` | typovaný výčet: přehrát/pauza, přetočit (absolutně/relativně), hlasitost, ztlumení, rychlost, výběr stopy, načíst titulky, posun titulků, velikost titulků, playlist (další/předchozí/skok/odebrat/přesunout), snímek obrazovky, kvalita streamu |
| `player_input(event)` | přeposlaný vstup (klávesa dolů/nahoru, pohyb myši, tlačítko, kolečko) |
| `surface_set_layout(layout)` | celé okno / mini přehrávač (obdélník) / skryto |
| `glass_set_regions(rects)` | zaoblené obdélníky skla nad videem |
| `thumb_request(time)` / `thumb_clear()` | náhled na časové ose |
| `settings_*`, `plugins_*`, `store_*`, `tools_*`, `system_*` | doménové operace modulů |

UI nemůže poslat libovolný příkaz mpv. Volná pole jsou jen tam, kde to doména vyžaduje
(např. hodnota nastavení pluginu), a validují se v Rustu.

Události Rust → UI:

| Událost | Obsah |
|---|---|
| `player:state` | dávka změn sledovaných vlastností (`pause`, `time-pos` max. 10×/s, `duration`, `volume`, `track-list`, `chapter-list`, `playlist`, `media-title`, `video-params`, `fullscreen`, …); UI interpoluje průběh |
| `player:file-loaded`, `player:end-file` | včetně důvodu a chyby |
| `player:message` | `script-message kaleido …` z `input.conf` (zkratky Kaleida) |
| `player:log` | filtrované zprávy logu mpv (chyby skriptů, ytdl_hook) |
| `player:engine-restarted` | po „Použít“ u pluginů |
| `plugins:changed`, `store:index-updated`, `tools:status` | stav domén |
| `system:open-request` | odkaz nebo soubory z jiné instance, protokolu či příkazové řádky |

## 5. Video a vstup

### 5.1 Okno a podokno

- Okno bez systémového rámečku, titulkový pruh kreslí UI. Tlačítko maximalizace vrací pro Windows
  `HTMAXBUTTON`, aby fungovalo menu rozložení (Snap Layouts) ve Windows 11.
- mpv kreslí do podokna pod průhledným WebView2. Podokno se synchronizuje s oknem (velikost,
  přesun, DPI, minimalizace).
- Než je video načtené, kreslí UI neprůhledné pozadí. Při přepnutí na fullscreen kryje okno černá
  clona, dokud mpv nevykreslí první snímek v nové velikosti.
- Fullscreen a „vždy navrchu“ se řídí vlastnostmi mpv: Kaleido sleduje `fullscreen` a `ontop`
  a promítá je do okna Tauri (a naopak). Fungují tak i zkratky z `input.conf` a pluginy.
  Příkaz `quit` z mpv ukončí aplikaci řádně (s uložením pozice).
- libmpv se inicializuje s `config=yes` a `config-dir=%APPDATA%\Kaleido`, takže čte standardní
  `mpv.conf`, `input.conf` a `scripts\`.

### 5.2 Výchozí konfigurace mpv

`osc=no`, `vo=gpu-next`, `gpu-api=d3d11`, `target-colorspace-hint=yes`, `hwdec=auto-safe`,
`autocreate-playlist=filter`, `save-position-on-quit=yes` (`watch-later-dir` v `state\`),
`deinterlace=auto`, `ytdl=yes` s `ytdl_hook-ytdl_path` na spravovaný yt-dlp a cestou k Deno přes
`ytdl-raw-options` (`js-runtimes`). Přesné hodnoty a verze mpv, které je podporují, ověří plán.

### 5.3 Vstup

- Veškerý vstup dostane WebView2. Co UI nezpracuje, přepošle do mpv: `keydown`/`keyup` s převodem
  názvů kláves (`KeyboardEvent.code` + modifikátory → názvy mpv), `mouse x y` v souřadnicích
  podokna (fyzické pixely), tlačítka a kolečko. Díky tomu fungují zkratky pluginů i jejich menu
  kreslená v obraze.
- **`input.conf` je jediný zdroj pravdy**, i pro zkratky Kaleida: ty se zapisují jako
  `script-message kaleido <akce>` a UI je dostane jako `player:message`.
- Výchozí `input.conf` Kaleida přepisuje základní vazby prefixem `no-osd` (hlasitost, přetáčení,
  rychlost) a zpětnou vazbu kreslí UI jako skleněný indikátor. OSD mpv zůstává pro pluginy
  (`show-text`).
- Textová pole v UI klávesy nepřeposílají.
- Když jsou vidět ovládací prvky, titulky se posunou nad spodní kapsli (okraj titulků přes vlastnosti mpv).

### 5.4 Ověřovací prototyp (milník M0)

Implementace začíná prototypem, který ověří nejrizikovější předpoklady. Kód prototypu se nepřebírá
automaticky, do M1 jde jen to, co projde review.

| # | Ověřit | Kritérium úspěchu |
|---|---|---|
| 1 | průhledné WebView2 nad D3D11 podoknem (gpu-next) | UI nad videem bez blikání při změně velikosti a přesunu, 60 fps |
| 2 | HDR | HDR10 video na HDR monitoru se zapnutým i vypnutým HDR ve Windows, UI nerozbije HDR výstup |
| 3 | přeposílání vstupu | klávesy s modifikátory, myš, kolečko; funguje `console.lua` a menu pluginu kreslené v obraze |
| 4 | fullscreen a DPI | přechody s černou clonou, přesun mezi monitory s různým DPI |
| 5 | **shader sklo** | rozmazání v oblastech zadaných za běhu přes `glsl-shader-opts`; do 1 ms GPU na snímek ve 4K; oblasti sledují animaci UI |
| 6 | mini přehrávač | podokno se hýbe synchronně s animací UI (jinak skok + prolnutí, viz 8.6) |
| 7 | thumbfast | `kaleido-mpv.exe` jako `mpv_path`; náhled přes `thumbfast-render` vykreslený v React bublině |
| 8 | snímek obrazovky | snímek nesmí obsahovat rozmazané oblasti skla (oblasti se před snímkem vynulují) |

Záložní řešení, pokud selže bod 1: dvě okna, video v hlavním okně a UI v průhledném vlastněném
okně nad ním. Pokud selže bod 5: nad videem jen tónované sklo bez rozmazání.

## 6. Plugin systém

### 6.1 Model

- Plugin = běžný mpv skript (Lua/JS, soubor nebo složka) + volitelně `script-opts`, shadery, fonty.
  **Žádné vlastní API.**
- Instalace do `scripts\<původní jméno skriptu>\` (jednosouborový skript jako `main.lua`/`main.js`),
  aby platilo `script-opts\<jméno>.conf`.
- Cíle souborů jsou omezené na `scripts\<jméno>\`, `script-opts\<jméno>.conf`, `shaders\` a `fonts\`.
  Jiné cesty (a `..`) instalace odmítne.

### 6.2 Evidence `plugins.json`

```json
{
  "version": 1,
  "plugins": {
    "thumbfast": {
      "source": "bundled | store | url | manual",
      "registryId": "thumbfast",
      "version": "…",
      "repo": "po5/thumbfast",
      "commit": "<sha>",
      "files": [{ "path": "scripts/thumbfast/main.lua", "sha256": "…" }],
      "enabled": true,
      "installedAt": "2026-10-11T12:00:00Z"
    }
  }
}
```

Ručně přidané skripty, které v evidenci nejsou, se zobrazí jako „ručně přidané“ (`source: manual`).

### 6.3 Životní cyklus

- **Instalace a zapnutí za běhu** přes `load-script`.
- **Vypnutí a odinstalace**: tlačítko „Použít“ → restart enginu a **pokračování na stejném místě**
  (playlist, pozice, vybrané stopy, pauza). Vypnuté pluginy se přesouvají do `scripts-disabled\`.
- Instalace je **atomická**: stáhnout → ověřit SHA-256 → dočasná složka → přesun. Při selhání se
  nic nezmění.
- **Nastavení pluginu**: formulář podle schématu v manifestu (6.5), jinak editor klíč = hodnota nad
  `script-opts\<jméno>.conf`, který zachová komentáře.

### 6.4 Essentials a vestavěné funkce

Předinstalované (`source: bundled`, kopie z `resources\essentials\` při prvním spuštění, aktualizace
přes katalog):

| Plugin | Účel |
|---|---|
| thumbfast | náhledy na časové ose (napojený na náš seekbar přes `thumbfast-render`) |
| sub-select | automatický výběr titulků podle preferencí |
| evafast | rychlé přetáčení / zrychlení na šipce |
| reload | obnova zaseknutého streamu |

Kritéria pro essentials: široce používaný, udržovaný, licence slučitelná s GPL-3.0, nekoliduje s UI,
bez dalších závislostí. Licence konkrétních verzí ověří plán.

Místo skriptů se používají vestavěné funkce mpv: `autocreate-playlist`, `save-position-on-quit`,
`ytdl_hook`, automatický deinterlace. **quality-menu se nepoužívá**: kvalitu streamů řeší nativně
UI (8.5).

### 6.5 Nekompatibilita

Pluginy nahrazující celé OSC (uosc, ModernZ) jsou v 1.0 označené jako **nekompatibilní**: v katalogu
je nejde nainstalovat (s vysvětlením) a ručně přidané se označí štítkem.

### 6.6 Nástroje

Přibalené (první kopie v instalátoru) a automaticky aktualizované do `%LOCALAPPDATA%\Kaleido\tools\`:

- **yt-dlp**: kontrola denně a vždy při chybě typu „zastaralý extraktor“. Stažení z GitHub Releases,
  ověření podle `SHA2-256SUMS`, atomická výměna mezi načteními. Kanál stabilní, volitelně nightly
  (Nastavení → Aktualizace).
- **Deno** (YouTube ho v yt-dlp vyžaduje): kontrola týdně, ověření kontrolního součtu.
- **ffmpeg v 1.0 není**: libmpv má vlastní, yt-dlp pro přehrávání vrací jen adresy streamů.
  Samostatný ffmpeg přijde s fází Stahování.

Logika podle downloaderu (`managed-binary`, `tool-freshness`, `tool-updates`), přepsaná do Rustu.

## 7. Obchod a katalog

### 7.1 Repo `kaleido-registry`

Samostatný podprojekt s vlastním plánem. Kontrakt s aplikací je v 7.2.

```
plugins/<id>/plugin.json     manifest: připnutý commit + SHA-256 souborů
media/<id>/                  ikona, snímky obrazovky
schema/plugin.schema.json
```

CI:
- **validate** (každý PR): schéma, stažení souborů, kontrolní součty, licence, zkušební načtení
  v mpv na Windows runneru, statická analýza → štítky oprávnění.
- **publish** (main): `index.json` podepsaný **ed25519** → GitHub Pages `…/v1/index.json` + `index.json.sig`.
- **watch** (denně): bot otevírá PR s novými verzemi pluginů.

Naplnění: import z mpv-script-directory → ruční výběr 50–100 skriptů.

### 7.2 Formát manifestu a indexu (v1)

```json
{
  "id": "thumbfast",
  "type": "script",
  "name": "thumbfast",
  "summary": { "en": "…", "cs": "…" },
  "description": { "en": "…", "cs": "…" },
  "authors": ["po5"],
  "license": "…",
  "homepage": "https://github.com/po5/thumbfast",
  "categories": ["interface"],
  "featured": true,
  "version": "…",
  "source": { "repo": "po5/thumbfast", "commit": "<sha>" },
  "scriptName": "thumbfast",
  "files": [
    { "src": "thumbfast.lua", "dest": "scripts/thumbfast/main.lua", "sha256": "…" }
  ],
  "permissions": ["exec"],
  "compat": { "kaleido": ">=1.0.0", "status": "ok | incompatible", "reason": { "en": "…", "cs": "…" } },
  "settings": [
    { "key": "max_height", "type": "int", "default": 200, "min": 50, "max": 600,
      "label": { "en": "…", "cs": "…" } }
  ],
  "media": { "icon": "media/thumbfast/icon.png", "screenshots": [] }
}
```

- `en` je povinné, `cs` volitelné; UI bez překladu zobrazí angličtinu.
- `permissions` počítá CI (statická analýza), ruční hodnota se jen porovná.
- Typy nastavení: `bool`, `int`, `float`, `string`, `enum`, `color`.
- `type: "theme"` je rezervované pro budoucí témata.
- `index.json` = `{ "version": 1, "generated": "…", "plugins": [ … ] }`. Aplikace obsahuje veřejné
  klíče (aktuální + příští kvůli rotaci) a index s neplatným podpisem odmítne.
- Soubory se stahují z `raw.githubusercontent.com/<repo>/<commit>/<src>` a ověřují podle `sha256`.

### 7.3 V aplikaci

- **Obchod → Objevovat**: doporučené (`featured`), kategorie Rozhraní / Titulky / Zvuk /
  Obraz a shadery / Streamy / Nástroje, hledání (na straně klienta nad indexem).
- **Detail**: popis, snímky, autor, licence, verze, odkaz na zdroj, **štítky oprávnění**
  (spouští programy / přistupuje k síti / čte a zapisuje soubory), kompatibilita.
- **Moje pluginy** (samostatná položka lišty): nainstalované včetně ručně přidaných, aktualizace,
  zapnout/vypnout, nastavení, odinstalace, štítek „hlásí chyby“ (10.4).
- Obnova indexu při startu a každých 6 h; offline se zobrazí cache. **Automatické aktualizace
  pluginů jen po zapnutí** (Nastavení → Pluginy).

### 7.4 Instalace z GitHub URL (pro pokročilé)

Volitelný `kaleido-plugin.json` v repu (stejný formát jako manifest), jinak heuristika (skript
v kořeni nebo složka s `main.lua`/`main.js`, `*.conf` → script-opts, `*.glsl` → shaders, fonty).
Před instalací **výrazné varování** a seznam souborů. Připnutí na commit, kontrola aktualizací
denně (porovnání s HEAD výchozí větve).

## 8. UI a vzhled

### 8.1 Liquid glass a design tokeny

- UI je **plně upravitelné**: barva skla, průhlednost, rozmazání, akcent (výchozí duhový
  „Kaleido“), zaoblení, tmavý/světlý/systém, přepínač Windows 11 Mica.
- Vše jsou **design tokeny** (CSS proměnné); komponenty berou hodnoty jen z nich. Skupiny: barvy,
  sklo (tónování, krytí, rozmazání, sytost), akcent, zaoblení, velikosti písma, mezery, stíny,
  pohyb (délky, křivky), fokus.
- Téma = manifest hodnot tokenů (budoucí `type: "theme"` v katalogu).

### 8.2 Sklo nad videem

CSS `backdrop-filter` video nevidí (je v nativním podokně pod WebView2). Proto **rozmazání dělá
GLSL shader v mpv s oblastmi** (zaoblené obdélníky); UI posílá jejich geometrii za běhu
(`glass_set_regions` → `glsl-shader-opts`). CSS dělá tónování, průhlednost, odlesky a lom.
Mimo video se používá běžný `backdrop-filter` a Mica/Acrylic. Ověřuje prototyp (5.4).

Technická lekce: ve WebView2 nedávat `transform: scale` na předky prvků s `backdrop-filter`
(chyba v Chromiu), použít `zoom` nebo nic.

### 8.3 Navigace

- **Boční lišta + mini přehrávač**: při přehrávání je lišta skrytá (otevře ji ☰ nebo najetí
  k levému okraji). Na stránkách se video zmenší do plovoucího mini přehrávače vpravo dole (díra
  v průhledném WebView2). Bez videa je lišta vidět a ukazuje se úvodní obrazovka.
- Položky lišty: **Přehrávač, Obchod, Moje pluginy, Nastavení** | Stahování, AI, Knihovna (ROADMAPA).

### 8.4 Ovládání přehrávače – „plovoucí ostrůvky“

- Kapsle vlevo nahoře: ☰, název, štítek rozlišení/HDR (z `video-params`).
- Kapsle vpravo nahoře: ovládání okna.
- Velká spodní kapsle: časová osa s náhledem z thumbfastu, hlasitost, předchozí/přehrát/další,
  titulky, kvalita, playlist, fullscreen.
- Ovládání i kurzor se při přehrávání skryjí po 2,5 s bez pohybu myši.

### 8.5 Klíčové obrazovky

1. **Úvodní obrazovka** (bez videa): zóna pro přetažení videa, „Otevřít soubor“, „Vložit odkaz“
   (Ctrl+V), karta „Pokračovat ve sledování“ (ROADMAPA) a „Co chystáme →“. „Vložit odkaz“ přehraje
   odkaz ze schránky; když ve schránce žádný není, objeví se malé pole pro vložení.
2. **Rychlé nastavení**: panel nad tlačítkem, které ho otevřelo; záložky **Titulky / Zvuk / Kvalita**
   (stopy, načíst ze souboru, velikost, posun). Stejně se nad svým tlačítkem otevírá i panel playlistu.
   - **Kvalita u streamů**: `tools` spustí `yt-dlp -J` souběžně s přehráváním, UI z výsledku sestaví
     seznam kvalit (převzatá logika formátů z downloaderu). Volba nastaví `ytdl-format` a načte
     stream znovu na stejné pozici.
3. **Odkazy**: Ctrl+V nebo přetažení odkazu kdekoli ho **rovnou přehraje** ve výchozí kvalitě
   (Nastavení → Přehrávání → „Výchozí kvalita streamů“). Během načítání ukazuje přehrávač název
   a indikátor načítání. Žádná karta náhledu ani paleta (viz 9.4).
4. **Nastavení → Vzhled** s živým náhledem; změny se projeví okamžitě, „Obnovit výchozí“.

Makety: `Apps\Kaleido\.superpowers\brainstorm\1883-1791720763\content\`
(`player-direction.html`, `pages-navigation-v2.html`, `key-screens-v2.html`; obrazovka 3 v nich
je překonaná bodem 3 výše).

### 8.6 Pohyb a animace

- Ostrůvky a panely se otevírají krátkou pružinovou animací (150–250 ms).
- Přechod do mini přehrávače: podokno mpv se hýbe přesně s UI. Pokud se to v prototypu nepodaří
  synchronizovat, podokno skočí na cílové místo a přechod zakryje prolnutí.
- `prefers-reduced-motion` (vypnuté animace ve Windows) → jen prolínání.

### 8.7 Typografie

Segoe UI Variable, na starších systémech Segoe UI. Čísla v časech mají pevnou šířku
(`tabular-nums`). Velikosti písma jsou tokeny: 11 / 12 / 13 / 15 / 20 / 28. Písmo titulků se nastavuje
zvlášť (Nastavení → Titulky).

### 8.8 Jazyky

Čeština a angličtina, výchozí podle jazyka systému (čeština → čeština, jinak angličtina). Texty jen
v `locales/cs.json` a `locales/en.json`; ESLint hlídá řetězce napsané natvrdo. Data a čísla přes `Intl`.

### 8.9 Přístupnost

- Celá aplikace ovladatelná klávesnicí: viditelný fokus (token), šipky v seznamech, Esc zavře panel
  nebo lištu.
- Sklo pod textem má spodní mez krytí a text jemný stín, aby zůstal čitelný nad jakýmkoli videem.
- **„Snížit průhlednost“**: sklo je neprůhledné a shader rozmazání se vypne (šetří GPU). Zapne se
  automaticky, pokud má Windows vypnuté efekty průhlednosti.
- Popisky pro čtečky obrazovky (ARIA → UIA). V režimu vysokého kontrastu Windows (`forced-colors`)
  se použijí systémové barvy.
- Měřítko UI 90–150 % (Nastavení → Vzhled, přes CSS `zoom`).

### 8.11 První spuštění

Krátký průvodce, který jde přeskočit:

1. Uvítání se třemi tipy: přetáhni video nebo vlož odkaz, ☰ otevře lištu, Obchod s pluginy.
2. **Výchozí přehrávač** (8.12).
3. **Import mpv configu**, pokud ho najde v `%APPDATA%\mpv\` nebo `portable_config`: zkopíruje se
   `mpv.conf`, `input.conf` a `script-opts`; skripty se zařadí jako „ručně přidané“; uosc a ModernZ
   dostanou štítek nekompatibilní. Původní složka se nemění.
4. Přehled předinstalovaných essentials s možností je vypnout.

### 8.12 Výchozí přehrávač

Windows 10/11 nedovolí aplikaci nastavit se jako výchozí sama a jedním klikem to umí jen
prohlížeče. Kaleido jde **povolenou cestou** (obcházení ochrany UserChoice je zamítnuté):

- Instalátor zaregistruje Kaleido jako aplikaci schopnou otevřít **všechny přípony, které mpv umí**
  (objeví se v „Otevřít pomocí“ i ve Výchozích aplikacích), ve skupinách
  **Video** (mkv, mp4, m4v, webm, avi, mov, wmv, flv, ts, m2ts, mts, mpg, mpeg, vob, ogv, 3gp,
  …), **Zvuk** (flac, mp3, opus, ogg, m4a, aac, wav, wma, mka, …) a **Playlisty** (m3u, m3u8, pls).
  Úplný seznam sestaví plán.
- Průvodce (8.11) a **Nastavení → Přehrávání → Výchozí přehrávač** mají zaškrtávátka skupin;
  výchozí zaškrtnutí: Video a Playlisty ano, Zvuk ne.
- U zaškrtnutých skupin se Kaleido nastaví jako výchozí pro přípony, které výchozí aplikaci ještě
  nemají. U ostatních Windows při prvním otevření nabídne „Jak chcete soubor otevřít?“.
- Stránka Výchozí přehrávač ukazuje stav po skupinách a u chybějících typů otevře systémový dialog
  „Otevřít pomocí“, případně stránku Kaleida ve Výchozích aplikacích (pokud ji daná verze Windows
  umí otevřít přímo, jinak obecnou stránku Výchozích aplikací).

## 9. Integrace zvenku

### 9.1 Protokol `kaleido://` (kontrakt v1)

```
kaleido://play?url=<URL-encoded http(s) URL>[&format=<yt-dlp formát>][&start=<sekundy>][&mode=replace|append]
```

- `url`: jen `http`/`https`. Odmítnuto vše ostatní, včetně `file://` a zvláštních protokolů mpv
  (`edl://`, `lavfi://`, `av://`, …).
- `format`: musí odpovídat syntaxi výběru formátů yt-dlp; nastaví se jako `ytdl-format` jen pro
  tuto položku.
- `start`: nezáporné číslo.
- `mode`: výchozí `replace`.
- Neznámé parametry se ignorují. Do mpv se nepředává nic jiného.

### 9.2 Příkazová řádka

`Kaleido.exe [--append] [--start=<s>] [--format=<f>] <soubor|složka|url>…`. Stejný parser
a validace jako u protokolu. Lokální soubory a složky zvenku (asociace, kontextové menu) přicházejí
jen touto cestou, protokol je nepřijímá; uvnitř aplikace se otevírají dialogem nebo přetažením.
Sloveso v kontextovém menu má `MultiSelectModel=Player`, aby víc vybraných souborů přišlo najednou.

### 9.3 Jediná instance

Další spuštění předá argumenty běžící instanci (`system:open-request`) a ukončí se. Soubor otevřený
za běhu **nahradí** aktuální přehrávání; v nastavení jde přepnout na „Přidat do playlistu“.
Požadavky, které přijdou do 300 ms po sobě, se spojí do jednoho playlistu.

### 9.4 Raycast

- **Zamítnuto:** příkazová paleta ani karta náhledu odkazu v Kaleidu nebudou. Bohatý workflow
  odkazů (náhled, výběr kvality, stahování) patří do Raycastu.
- **Do budoucna:** extension v Raycastu napojená na Kaleido přes `kaleido://` (9.1). Jestli to bude
  akce v The Downloader (PR https://github.com/raycast/extensions/pull/31720), nebo samostatná
  extension, se rozhodne po 1.0. Kaleido 1.0 dodá jen kontrakt a jeho dokumentaci.
- Kaleido spravuje vlastní yt-dlp a Deno a **nesdílí** složku nástrojů s downloaderem (nezávislé
  aktualizace, žádné zámky mezi aplikacemi).

## 10. Chyby a odolnost

### 10.1 Princip

Každá chyba má srozumitelnou zprávu (CZ/EN), akci k nápravě a rozbalitelné „Podrobnosti“ s úryvkem
logu. Nic neselže potichu.

### 10.2 Přehrávání

Soubor nejde přehrát (nepodporovaný, poškozený, chybí) → karta v přehrávači; playlist pokračuje
dalším souborem. Zdroj: `end-file` s chybou.

### 10.3 Streamy

Kaleido třídí chyby yt-dlp podle zpráv `ytdl_hook` v logu mpv:

| Třída | Akce |
|---|---|
| zastaralý yt-dlp / změněný web | „Aktualizovat a zkusit znovu“ (jedním klikem) |
| vyžaduje přihlášení nebo věk | „Použít cookies z prohlížeče“ (výběr prohlížeče, logika `browsers.ts`) |
| zablokovaný region, soukromé nebo smazané video | jen vysvětlení |
| výpadek sítě | „Zkusit znovu“ |

### 10.4 Pluginy

Chybové zprávy v logu mpv nesou jméno skriptu → přiřadí se k pluginu přes `plugins.json`. Plugin
dostane v Moje pluginy štítek „hlásí chyby“ s logem a jednou se ukáže nenápadná notifikace
s „Vypnout“. Nic se nevypíná automaticky.

### 10.5 Pády

- libmpv běží v našem procesu, takže jeho pád shodí celé Kaleido. Minidump zapíše hlídací proces
  (4.1), k němu se uloží log.
- Kaleido každých 10 s ukládá pozici přehrávání do `state\resume.json`. Po pádu nabídne pokračovat
  na stejném místě a **„Nahlásit“**: otevře předvyplněné GitHub issue; diagnostiku uživatel vidí
  a přikládá sám. **Nic se neodesílá automaticky.**
- **Bezpečný režim**: dva pády po sobě během startu → další start bez pluginů a bez shaderu skla,
  s nabídkou najít viníka (postupné zapínání).

### 10.6 GPU

Když selže shader skla nebo D3D11, sklo se automaticky přepne na neprůhledné (jako „Snížit
průhlednost“) a zapíše se to do logu.

### 10.7 Katalog a instalace

Index s neplatným podpisem se zahodí, použije se cache a uživatel dostane upozornění. Instalace
pluginu je atomická. Chyba stažení nástroje → opakování s odstupem, offline se nástroj nemění.

### 10.8 Logy a diagnostika

`%LOCALAPPDATA%\Kaleido\logs\` s rotací 7 dní: `kaleido.log` (Rust `tracing`) a `mpv.log`.
„O aplikaci“ → „Otevřít složku s logy“ a „Zkopírovat diagnostiku“ (verze Kaleida, libmpv, yt-dlp,
Deno, Windows, GPU, seznam pluginů; **bez cest k souborům a bez URL**).
